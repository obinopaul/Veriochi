## Veriochi (formerly "plane") — Documentation index

This `docs/` folder contains an incremental, developer-focused audit of the repository.

- `overview.md` — high-level project summary and purpose.
- `architecture.md` — architectural diagram and responsibilities.
- `apps.md` — per-app descriptions (web, admin, api, live, space, proxy).
- `packages.md` — per-package summaries for workspace libraries (propel, ui, services, etc.).
- `deployment.md` — docker-compose, Dockerfiles, infra notes, and deployment steps.
- `development.md` — how to run and develop locally, environment variables and shortcuts.
- `rename-to-veriochi.md` — step-by-step rename checklist and safety notes.
- `license.md` — notes about AGPL-3.0 implications for reuse and commercial use.

This initial set is intentionally high value and iterative: I'll continue filling these files with deeper, line-level notes as I read more source files. If you'd like a different structure, tell me and I'll adapt.
